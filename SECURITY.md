# Reporting security issues

Please use [GitHub private vulnerability reporting](https://github.com/andersj05/ComputerCat/security/advisories/new)
for vulnerabilities. Avoid posting credentials, screenshots containing private information,
or exploit details in a public issue.

This project is an early development build. Current supported code is the latest `main` branch.
The initial release has no computer-control tools. Please include the version, operating system,
reproduction steps, and expected versus observed behavior in a report.
