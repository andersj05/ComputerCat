# Handoff: task title

Status: in progress / blocked / ready for review
Updated: YYYY-MM-DD
Owner: task or role, not personal contact information
Branch: exact branch
Baseline: exact commit inspected

## Objective and constraints

State the requested outcome, remaining scope, and relevant user constraints.

## Work present

List relevant commits and files. Distinguish committed changes, uncommitted changes, and
unrelated pre-existing work. Use relative links for real files; do not invent paths.

## Verified facts and decisions

State observations and link evidence. Separate implemented behavior from proposals and
uncertainty. Promote durable facts to the shared topic documents instead of duplicating them.

## Verification

Record each command, outcome, and the revision or uncommitted changes tested. State what was
not run and why. Include only useful failure summaries; no credentials or raw tool logs.

## Remaining work and next action

List the concrete next step, unresolved questions, and blockers. Link any existing review or
issue if relevant. A receiver must recheck branch/status and current authorization before acting.
